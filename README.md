# Typeform Clone - HTML & CSS Practice Project

This is a **frontend-only project** created for practice purposes. The goal of this project was to replicate the design and responsiveness of the [Typeform](https://www.typeform.com/) website. It was built using **pure HTML and CSS** with a focus on responsive design.

---

## 📌 Features

- **Pixel-perfect design**: Replicates the main design of the Typeform website.
- Fully **responsive layout** for desktops, tablets, and mobile devices.
- Clean and reusable HTML structure.
- CSS techniques such as **flexbox**, **grid**, and **media queries**.
- Lightweight and optimized for performance.

---

## 🛠️ Technologies Used

- **HTML5**: For building the structure of the website.
- **CSS3**: For styling, layout, and responsiveness.
